

# QNN-BiGRU for Cloud Workload Forecasting

This repository contains the Python implementation of the QNN-BiGRU model proposed in the research paper:

**"Quantum-Enhanced BiGRU Model for Accurate and Efficient Cloud Workload Forecasting."**

The model combines a Bidirectional Gated Recurrent Unit (BiGRU) architecture with a quantum layer for cloud workload forecasting.

The quantum circuit is implemented using PennyLane and integrated with the classical deep learning framework.

## Code

The repository includes the Python source code implementing the proposed QNN-BiGRU model.

## Dataset

The experiments use a selected subset of the publicly available Google Cluster Usage Traces v3 dataset.

Original dataset: [https://github.com/google/cluster-data](https://github.com/google/cluster-data/blob/master/ClusterData2019.md)

## Availability

The source code is provided for research transparency and reproducibility.
